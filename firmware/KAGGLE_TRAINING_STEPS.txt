PesoLens ESP32-S3 Kaggle Training Steps
Date: 2026-05-26

Goal:
Train a smaller YOLO model on Kaggle's free GPU, export it to INT8 TFLite,
and check if it is small enough for ESP32-S3 firmware.

Prepared local dataset ZIP:
C:\Users\Lester Valdez\PesoLens-fixed-2026-05-12\PesoLens\pesolens-balanced-esp32-kaggle.zip

Step 1 - Create a private Kaggle dataset
1. On Kaggle dashboard, click Create or + New.
2. Choose New Dataset.
3. Upload:
   pesolens-balanced-esp32-kaggle.zip
4. Name it:
   pesolens-balanced-esp32
5. Keep it Private if Kaggle gives that option.
6. Click Create.

Step 2 - Create a Kaggle notebook
1. Go to Code or Notebooks.
2. Click New Notebook.
3. On the right-side panel, open Settings.
4. Set Accelerator to GPU. Use T4 if available.
5. Turn Internet on if there is an option.

Step 3 - Attach your dataset
1. In the notebook right panel, click Add Input or Add Data.
2. Search/select your dataset:
   pesolens-balanced-esp32
3. Add it to the notebook.

Step 5 - Find the uploaded ZIP path
Run this cell:

from pathlib import Path

for p in Path("/kaggle/input").rglob("*.zip"):
    print(p)

Expected result should look like:
/kaggle/input/pesolens-balanced-esp32/pesolens-balanced-esp32-kaggle.zip

If nothing prints but Kaggle shows thousands of files in the dataset, Kaggle
already unpacked the dataset. In that case, skip Step 6 and use this cell
instead:

from pathlib import Path
import yaml

for p in Path("/kaggle/input").iterdir():
    print(p)

source_data_yaml = next(Path("/kaggle/input").rglob("data.yaml"))
dataset_root = source_data_yaml.parent

cfg = yaml.safe_load(source_data_yaml.read_text())
cfg["path"] = str(dataset_root)
cfg["train"] = "train/images"
cfg["val"] = "valid/images"
cfg["test"] = "test/images"

data_yaml = Path("/kaggle/working/pesolens_data.yaml")
data_yaml.write_text(yaml.safe_dump(cfg, sort_keys=False))

print(data_yaml)
print(data_yaml.read_text())

Step 6 - Unzip the dataset
Run this cell:

from pathlib import Path
import zipfile

zip_path = next(Path("/kaggle/input").rglob("pesolens-balanced-esp32-kaggle.zip"))
work = Path("/kaggle/working/datasets")
work.mkdir(parents=True, exist_ok=True)

with zipfile.ZipFile(zip_path, "r") as zf:
    zf.extractall(work)

data_yaml = work / "pesolens-roboflow-balanced-esp32-v2" / "data.yaml"
print(data_yaml)
print(data_yaml.read_text())

Step 7 - Train the smaller ESP32-targeted model
Run this cell:

from ultralytics import YOLO

model = YOLO("yolov8n.pt")

results = model.train(
    data=str(data_yaml),
    epochs=50,
    imgsz=160,
    batch=16,
    patience=15,
    device=0,
    project="/kaggle/working/pesolens-esp32-runs",
    name="yolov8n-imgsz160-balanced",
)

Step 8 - Export INT8 TFLite
Run this cell:

best = "/kaggle/working/pesolens-esp32-runs/yolov8n-imgsz160-balanced/weights/best.pt"

model = YOLO(best)
export_path = model.export(
    format="tflite",
    int8=True,
    imgsz=160,
    data=str(data_yaml),
)

print(export_path)

Step 9 - Check TFLite file size
Run this cell:

from pathlib import Path

for p in Path("/kaggle/working").rglob("*.tflite"):
    mb = p.stat().st_size / (1024 * 1024)
    print(f"{mb:.2f} MB | {p}")

Size target:
1-3 MB    = good
3-4.5 MB  = maybe usable
over 4.5 MB = too large for flash embedding

Notes:
- If imgsz=160 is too large or too slow, repeat with imgsz=128.
- The smaller model may be less accurate than the current laptop model.
- For the live ESP32 demo, use one bill at a time, centered, close, and in good lighting.
