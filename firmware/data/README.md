# firmware/data — audio clips for SPIFFS

This folder is uploaded to the XIAO's SPIFFS partition by `pio run --target uploadfs`. The firmware streams these clips through I2S → MAX98357A → bone-conduction speaker.

## Format spec — every WAV in this folder MUST match

| Property | Value |
|---|---|
| Container | WAV (RIFF / PCM) |
| Sample rate | 16000 Hz |
| Channels | 1 (mono) |
| Sample format | 16-bit signed little-endian PCM |

Clips outside this spec play at the wrong speed/pitch (audio.cpp does not resample) or fail to load.

## Where these come from

Generated by `../tools/generate_english_clips.py` using Microsoft Edge's neural voices via `edge-tts`. Idempotent — re-running skips existing files. To regenerate one clip, delete its WAV first.

## What clips exist

This folder currently contains the generated English clips needed to announce totals for all six bill classes through composed numbers: digits, teens, tens, `hundred`, `thousand`, `peso`, `pesos`, `and`, plus `beep` and `error` tones.

## Smaller / silent placeholders

Before real clips are generated, `../tools/make_placeholders.py` writes 1-second silent WAVs that match the format spec, so the firmware build and SPIFFS upload still succeed. The output is silent — useful for compile/flash testing only.
