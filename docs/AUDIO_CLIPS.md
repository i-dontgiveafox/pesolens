# Audio clips — English

Every WAV file the firmware can play. Auto-generated by `firmware/tools/generate_english_clips.py` using `edge-tts` (Microsoft Edge neural voices, default `en-US-AriaNeural`). Stored in `firmware/data/` and uploaded to SPIFFS via `pio run --target uploadfs`.

## Format spec (every clip must match)

| Property | Value |
|---|---|
| Container | WAV (RIFF) |
| Sample rate | 16000 Hz |
| Channels | 1 (mono) |
| Sample format | 16-bit signed PCM |
| Approx. length | 0.4 - 1.0 s for spoken words; 0.2 s for `beep`; 0.4 s for `error` |

## How example announcements map to clips

- `1 peso` → `one` + `peso`
- `20 pesos` → `twenty` + `pesos`
- `131 pesos` → `one` + `hundred` (+ `and`) + `thirty` + `one` + `pesos`
- `730 pesos` → `seven` + `hundred` (+ `and`) + `thirty` + `pesos`
- `1000 pesos` → `one` + `thousand` + `pesos`
- `1730 pesos` → `one` + `thousand` + `seven` + `hundred` (+ `and`) + `thirty` + `pesos`

The maximum total in scope (six ₱1000 bills detected at once = 6000 pesos) is well within reach with this clip set.

## Regenerating

```
cd firmware
python tools/generate_english_clips.py            # default voice (en-US-AriaNeural)
python tools/generate_english_clips.py --voice en-GB-SoniaNeural   # British female
python tools/generate_english_clips.py --voice en-US-GuyNeural     # American male
```

Existing clips are skipped — delete a WAV first if you want to regenerate it. `edge-tts --list-voices` prints every available voice.
